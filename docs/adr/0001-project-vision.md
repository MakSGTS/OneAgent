# ADR-0001: Project Vision

## Status

Accepted

## Decision

OneAgent is an AI development platform for 1C:Enterprise.

- Rust Runtime is the core.
- VS Code is the primary IDE integration.
- MCP is an external adapter.
- The primary development platform is macOS Apple Silicon.
- Windows and macOS Apple Silicon are supported targets.
- Language models receive structured semantic data instead of raw project dumps.
