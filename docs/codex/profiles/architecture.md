# Architecture Profile

## Purpose

Use this profile for architecture-only work: ADRs, unresolved semantic contracts,
source-contract decisions, endpoint matrices, roadmap architecture, and deferred
scope decisions.

## Required Workflow modules

- `docs/codex/workflows/architecture.md`

## Task-family expectations

- Separate accepted facts, repository evidence, alternatives, decisions, and
  open questions.
- Record the chosen architecture and rejected alternatives.
- Do not implement production behavior unless the task explicitly includes it.
- Do not mark capabilities as supported based on architecture documentation
  alone.
