# Implementation Profile

## Purpose

Use this profile for implementing one accepted capability or behavior when the
architecture is already decided.

- `docs/codex/core/repository-safety.md`
- `docs/codex/core/repository-investigation.md`

## Required Workflow modules

- `docs/codex/workflows/implementation.md`

## Task-family expectations

- Reference accepted ADRs and architecture documents instead of restating them.
- Keep the implementation slice coherent and bounded.
- Do not reselect architecture during implementation.
- Add focused tests and update documentation only when behavior changes.
