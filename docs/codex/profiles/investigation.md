# Investigation Profile

## Purpose

Use this profile for read-only repository, architecture, source-format, fixture,
or implementation evidence investigation.

## Required Core modules

- `docs/codex/core/repository-safety.md`
- `docs/codex/core/repository-investigation.md`
- `docs/codex/core/validation.md`
- `docs/codex/core/final-report.md`

## Required Workflow modules

- None by default.
- Add `docs/codex/workflows/architecture.md`, `docs/codex/workflows/parser.md`,
  `docs/codex/workflows/graph-model.md`, or `docs/codex/workflows/graph-emission.md`
  only when the investigation is specific to that workflow.

## Task-family expectations

- Do not modify files unless the task explicitly allows investigation notes.
- Classify findings as confirmed, probable, or unknown when source evidence is
  incomplete.
- Stop before implementation when required evidence is missing.
