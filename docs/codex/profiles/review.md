# Review Profile

## Purpose

Use this profile for review-only tasks over a completed implementation, document
set, diff, or architecture change.

## Required Core modules

- `docs/codex/core/repository-safety.md`
- `docs/codex/core/repository-investigation.md`
- `docs/codex/core/validation.md`
- `docs/codex/core/final-report.md`

## Required Workflow modules

- `docs/codex/workflows/review.md`

## Task-family expectations

- Do not change files unless the user explicitly converts the review into an
  implementation task.
- Prioritize confirmed findings by severity.
- Separate missing evidence from defects.
- Compare against accepted ADRs, architecture documents, tests, and task scope.
