## Deferred scope

The sprint reviews and ADRs retain their exact domain-specific exclusions.
Broader source grammars and semantic families, effective authorization,
runtime dispatch, whole-graph cross-adapter equality, flat Designer dumps,
extensions, persistence, long-running Runtime services, transport APIs, CLI
product behavior, AI, MCP, LSP, IDE integration, packaging, publication,
benchmarks, and performance/security hardening remain assigned to later
roadmap work.

## State transition

v0.3 — 1C Knowledge Model is complete. Sprint 15 — Runtime Service Container
is the unique `next` planning target. Its kickoff must first satisfy the planned
Runtime Services and APIs Codex Framework readiness stage and then revalidate
the live Runtime architecture and implementation baseline.

The complete Sprint 14 prompt suite and reusable bootstrap prompt remain
unchanged. Prompt retirement is not a release-review action.

## Conclusion

v0.3 delivers the accepted broader 1C knowledge model across EDT sources and
the bounded Designer XML adapter while preserving canonical graph identity,
provenance, deterministic consumers, and explicit incomplete knowledge. The
release boundary passes, and dependency-ordered planning may continue with
Sprint 15.
