## Findings, missing evidence, and release risks

### Blocking

None.

### Non-blocking follow-ups and limitations

1. Pinned VS Code Extension Host runs may emit a platform bootstrap `SIGPIPE`
   diagnostic while every test and Host process still exits successfully.
2. Cursor Agent's public non-interactive CLI exposes discovery but no direct
   tool-call command. Codex direct calls and synthetic public-process tests
   cover the server call boundary; no Cursor direct-call result is claimed.
3. Cursor approval state and ignored client artifacts are not reproducible from
   Git bytes alone. The committed evidence records exact versions, hashes,
   commands, scope, and limitations without tracking mutable client state.
4. The accepted EDT evidence proves the bounded compatibility probe and p2
   package, not a semantic EDT workflow or general EDT-version compatibility.

No mandatory v0.6 evidence is missing. The Sprint 35 evidence-wording and
targeted protocol-test follow-ups are resolved by `5d8f0403`.

## Deferred scope

Remote MCP transports, authentication, prompts/resources/completions,
concurrent or cancellable in-flight tool calls, pagination, mutable snapshots,
additional client claims, automatic client configuration, definition and
reference providers, document synchronization, diagnostics UI, semantic EDT
navigation or editing, automatic Context collection, model tools or edits,
Runtime packaging, Marketplace publication, signing, telemetry, benchmarks,
and stable public compatibility guarantees remain assigned to later work.

## State transition

v0.6 — MCP and IDE is complete. Sprint 36 — Diagnostics Engine is the unique
`next` planning target. Its kickoff must preserve Graph as semantic authority,
reuse recoverable diagnostic evidence, and define orchestration, rules,
ordering, suppression, bounds, and reporting before implementation.

The Sprint 35 prompt suite remains unchanged. Prompt retirement is not a
release-review action.

## Conclusion

v0.6 delivers bounded MCP and LSP processes, semantic tools, desktop VS Code
navigation/Context/chat, a native EDT compatibility probe, and exact Codex and
Cursor compatibility evidence while preserving graph, semantic, protocol,
policy, lifecycle, resource, and security ownership. The release boundary
passes with the explicit non-blocking limitations above.
